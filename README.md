# zNote

个人文本编辑器与 Markdown 写作工具。Tauri 2 + Rust 提供本地文件能力，Vue 3 + CodeMirror 6 提供单编辑内核与写作界面。当前版本 **0.1.6**，支持 Windows x64 与 macOS arm64。

界面使用 Segoe UI 搭配内置 Noto Sans SC。所有格式的文档编辑区与预览区统一使用本机字体：英文优先 Cascadia Code，未安装时使用 Consolas；中文优先思源黑体（Source Han Sans SC / CN），未安装时使用微软雅黑。正文、代码块和行内代码默认均为 14 px，可在“帮助 → 设置 → 字体大小”中调整为 10–32 px 的整数，对所有标签即时生效并在重启后保留；Markdown 标题按正文字号成比例调整。TXT、LOG 和 Markdown 正文行高为 1.7，JSON/CSV 等结构化文本行高为 1.6。JSON 两侧操作位于独立工具区，不覆盖正文。此设置不改变菜单等界面字号，也不改变导出文件的字体与排版。

macOS 界面优先使用系统字体，文档英文优先 Menlo / Monaco，中文优先思源黑体并回退到苹方。标题栏左侧保留系统红黄绿按钮（关闭、最小化、全屏），文档名与未保存圆点居中；菜单与专注按钮避让窗口控件。系统菜单提供设置、隐藏、退出、编辑与窗口操作。Finder 打开文件复用已有文本格式识别，退出前保存恢复会话。

## 首版功能

- 大纲宽度与编辑/预览比例支持拖动、方向键调整和双击复位，并记住本机偏好；窗口缩小时保留可用空间。大纲标记当前光标所在章节。标签支持方向键、Home/End 导航，自动显示活动标签，未保存状态增加圆点。标题栏专注按钮或 Ctrl+Shift+Enter 隐藏/恢复大纲和标签栏；没有其他浮层或搜索时 Escape 退出专注模式。图标提示支持悬停和键盘焦点；系统减少动态效果时关闭界面过渡。

- 多标签、独立撤销历史、行号、自动换行、搜索替换。标签按文本、Markdown、JSON（含 GeoJSON）和 CSV 显示对应图标；未保存文档的图标为红色。鼠标中键可关闭标签，未保存时先提示。顶部菜单提供文件、编辑、格式和帮助操作；帮助中的设置可调整主题及当前文档的保存编码、换行格式。
- 无可恢复文档时打开空白 `.txt`，不生成欢迎文档。临时标签依次命名为 `未命名1.txt`、`未命名2.txt` 等，避开已有编号；重启保留名称，旧版同名临时标签会补编号。打开本地文档按 `.md` / `.markdown`、`.json` / `.jsonc` / `.geojson`、`.csv` 后缀识别格式。Markdown、CSV 默认原位显示，JSON（含 JSONC、GeoJSON）默认分屏，其他类型默认源码显示。格式菜单中的“显示为 Markdown / CSV / JSON”仅调整当前标签的解析和预览，不改文件名与保存路径；编辑后仍保存到原文件。新建文档、TXT 和其他普通文本文件可用，已保存的 Markdown、JSON/GeoJSON、CSV 文件置灰。“转为 Markdown / CSV / JSON”仅对新建文档和本地 `.txt` 文件可用；已保存的 Markdown、JSON/GeoJSON、CSV 文件置灰，其他后缀不显示。转换本地 `.txt` 时保留原文件，后续保存以新后缀另存为。转为 JSON 后对非空内容执行可撤销的格式化。手动选择的显示模式在当前标签内保留，切换标签不会沿用其他文档的模式。
- 所有本地文件均可尝试以文本打开，不按扩展名限制；支持 `.py`、`.java`、`.yml`、`.yaml`、其他代码/配置文件及 `Dockerfile`、`Makefile`、`.env` 等无扩展名文件。原生打开对话框默认显示所有文件；Markdown、JSON/JSONC/GeoJSON 和 CSV 保留对应显示，其余按普通文本显示，保留原文件名。仍执行 20 MiB 上限及 UTF-8、GBK、带 BOM 的 UTF-16 解码检查；包含 NUL 或无法无损解码的内容拒绝打开。
- Windows 安装版只为常见文本扩展名注册“打开方式 → zNote”候选，并为任意文件提供“使用 zNote 打开”右键入口（Windows 11 可能位于“显示更多选项”）。不设置默认应用、不写文件类型图标、不改 Windows UserChoice；文件保留原默认程序和图标。安装时仅恢复仍指向旧版自动关联的扩展名默认值；若旧备份已被重复安装覆盖，则移除该用户层默认值，回退系统关联。用户在 Windows 中主动选择的默认应用不由安装程序更改。打开的文件会交给现有 zNote 窗口，或启动新窗口；未编辑时显示已保存，首次主动保存仍需通过原生保存对话框确认路径，无扩展名文件不自动追加 `.txt`。
- 关闭当前标签后默认选中紧邻左侧的标签；最左侧标签关闭时选中右侧标签。通过文件关联打开文档时，已最小化的 zNote 窗口会恢复并置于前台。
- Markdown 源码、原位、分屏预览；新标签的原位宽度默认标准（最大 960px），格式菜单的“Markdown 设置”可为当前标签选择全宽、标准或紧凑（最大 720px），后两档居中显示并随窗口缩窄。已有标签保留会话中保存的宽度选择；这项显示设置不改动文档内容。原位与分屏共用 CommonMark/GFM 解析，排版标题、强调、列表与任务框、链接、引用、表格、代码块、分隔线、脚注及行内/块级公式。原位点击排版块会显示该块的 Markdown 原文供编辑，离开后重新排版。`mermaid` 与 Mermaid 风格的 `flowchart` 围栏显示 Mermaid 图；`flow` 与 flowchart.js 风格的 `flowchart` 围栏显示 flowchart.js 图。分屏预览按语言高亮普通代码块。编辑器自动补全括号与引号。
- Markdown、JSON 和 CSV 分屏时，两侧按内容锚点同步纵向滚动；点击源码或右侧结构预览会高亮并定位对应内容。JSON 右侧默认显示只读结构视图，按解析节点对应源码字符位置，不要求两侧显示行号相同。双栏左侧右上角的“转义”和“去除转义”修改整份源码，可撤销且不会自动保存；转义生成带外层引号的 JSON 字符串，去除转义解开一层且结果须符合当前格式的 JSON 规则。右侧右上角的“压缩”和“展开”仅在内容按当前格式合法解析时出现，切换到只读紧凑文本或缩进文本预览，再次点击当前按钮返回结构视图。两种文本预览支持选择复制及“复制预览全文”，复制内容与当前预览一致，不改动源码；JSONC 压缩保留注释及必要换行。
- 打开 `.csv` 后默认原位显示表格；默认将首行作为表头，自动识别分隔符，并同时解析普通字段和双引号字段，支持字段内分隔符与换行。拖拽首行单元格右边界可调整列宽，聚焦边界后也可用左右方向键微调；列宽随标签会话恢复。格式菜单的“CSV设置”可为当前标签选择分隔符（含自定义字符）、引号转义方式、是否以首行为表头及是否跳过空行；这些设置只影响预览，不改动文件内容或保存状态。点击表格记录切到对应源码位置，也可手动切换源码或分屏编辑并保存原 CSV。
- JSON 原位模式进入时通过 Worker 将合法内容格式化为展开的可编辑正文，修改计入撤销历史且不会自动保存；语法错误时保留原文并提示错误。分屏右侧预览仍为只读。
- 转为 JSON 时通过 Worker 格式化，保留大整数和重复键字面值；`.json`、`.geojson` 及临时文本显示为 JSON 时使用严格校验，`.jsonc` 允许注释与尾逗号。右侧压缩与展开不经 `JSON.parse` 重建数据，不丢失大数字、重复键或 JSONC 注释。格式菜单不提供单独的 JSON 或代码块格式化命令。
- 原生打开、保存、另存为；支持 UTF-8、GBK、带 BOM 的 UTF-16LE/BE 文件。底栏和设置中可选择 UTF-8 或 GBK 作为保存编码，新建文档默认 UTF-8；帮助菜单“设置”中可选择换行格式。
- 当前 Markdown 标签可通过文件菜单“导出”生成 Word `.docx` 或 PDF `.pdf`，由原生对话框选择保存位置；导出使用当前未保存的编辑内容，不改变原文件与未保存状态。
- 外部修改冲突检测、Windows 原子替换保存、只读文件保护。
- 退出时自动保存整个会话，不询问是否保存文档，也不将未保存修改写入原文件。重启恢复临时文档、已保存和已修改文件、标签顺序与当前标签、各标签撤销/重做历史、选区、滚动位置、显示格式/模式、CSV 设置与大纲折叠状态。仅关闭临时或未保存标签时提示保存、取消或不保存；选择不保存后该标签不再恢复。Light 浅色与 Dark 深色主题。Markdown 文档大纲按标题层级显示，含子标题的节点可独立折叠；底栏按钮可收起或展开整个大纲栏，其他格式不显示该按钮。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+N / Ctrl+O | 新建 / 打开 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+W | 关闭当前标签，未保存时提示 |
| Ctrl+F | 查找与替换 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+D / Ctrl+L | 向下复制当前行 / 删除当前行 |
| Ctrl+Shift+↑ / Ctrl+Shift+↓ | 向上 / 向下移动整行 |
| Alt+Shift+左键（可拖动） | 从当前光标到点击位置建立矩形多行选区，短行截到行尾 |
| Ctrl+左键 | 在任意位置添加光标，可跨行同时编辑 |
| Esc（多个光标时） | 仅保留主光标 |

多行选区支持同时输入、删除、剪切、复制、粘贴和撤销；左右方向键在各行行首、行尾停止，不跨行，Shift+左右方向键可同时扩展选区。上下方向键同时移动各光标。普通左键点击恢复单光标。编辑菜单粘贴将完整剪贴板文本插入每个选区。

macOS 对应使用 Command（⌘），重做为 ⌘+Shift+Z；⌘+, 打开设置，⌘+Q 保存恢复会话后退出，⌘+H 保留系统隐藏应用行为。界面菜单按平台显示快捷键。

编辑菜单的复制、剪切、粘贴和纯文本粘贴针对当前编辑器选区；“查找与替换”打开右上悬浮面板，拖动标题可临时移位，关闭后重新打开回到右上角。帮助菜单显示当前安装版本；安装版的“检查更新”从 GitHub Releases 获取签名更新包，发现新版本后自动后台下载，下载期间可继续编辑；检查更新按钮右侧显示下载百分比（服务器未提供总大小时显示“下载中…”）。下载完成后保存最新恢复会话、安装并重启；下载失败可重新检查更新。操作结果以短暂提示显示。浏览器开发预览只验证编辑界面，本地打开、保存、恢复与更新需要桌面版。

Light 浅色主题使用 `#f3f2ee` 背景与 `#1f0909` 正文。Dark 深色主题使用中性深色层级：标题栏近黑，编辑区为 `#1f1f21`，弹层和选中态以灰阶区分；保留克制的冷灰强调色，避免大面积偏蓝。顶栏菜单采用更小的字号与间距，并使用次级文字色。

保存编码、换行格式、Markdown 宽度与 CSV 设置共用主题化下拉组件，与顶栏及右键菜单保持一致。支持方向键、Home/End 定位、Enter/空格确认、Esc 收起和 Tab 切换焦点；底栏下拉自动向上展开，选中项显示勾选标记。
CSV 设置和查找替换的复选框使用统一主题外观，保留原生勾选语义、空格切换和焦点提示。文本输入、导出展开栏和主题分段选择沿用主题化控件；打开、保存等系统文件对话框保留 Windows 原生界面。

## 首版边界

- 原位模式按块切换排版与源码，不提供单元格级可视化表格编辑。图片显示占位文字，不读取本地图片路径或请求远程资源；原始 HTML 仍按文本处理。图表源码超过 2 万字符或语法错误时保留源码显示。暂不提供目录树、插件或云同步。
- 导出仅支持 100 万 UTF-16 字符以内的 `.md` / `.markdown` 文档。保留常用标题、段落、强调、列表、引用、代码块和表格；图片以占位文字输出，不嵌入图片。PDF 内置 Noto Sans SC 字体以支持中文。
- Markdown、JSON 使用各自的语法扩展；普通文本和 CSV 使用文本编辑，不提供 IDE 级语言服务。
- 单文件读取和保存上限为 20 MiB；仅 CSV 支持大文件结构化预览。Markdown、JSON（含 JSONC、GeoJSON）超过 100 万 UTF-16 字符时，打开和会话恢复均退化为 TXT 源码显示，不提供语法高亮、大纲或预览；不改变原文件名、内容、编码、BOM 与换行。编辑跨过此阈值时也退化为 TXT。大文件提醒位于底栏左侧。大文件默认不折行，可在“格式 → 自动折行”切换，仍可编辑、查找和保存。
- CSV 在后台解析，表格按可见行列加载，大文件也可预览、跳行及定位源码。解析可取消或重新开始；编辑或修改 CSV 设置后自动重新解析。单元格单行省略显示，最多显示 4,096 字符，复制保留完整字段；超过 100,000 列时使用固定列宽。后台索引仍占用内存，此实现不扩大单文件上限。
- CSV 表格预览的行列统计、跳行与解析控制位于底栏右侧，源码模式仍显示光标行列位置。
- 普通及大 CSV 预览左侧显示固定行号，横向滚动时保留；行号按解析记录计数，首行表头为第 1 行，多行字段仍计为一条记录。点击行号定位原文。
- 会话约在最后一次编辑或标签状态变化 1.5 秒后原子写入；正常退出会立即写入并等待成功。会话文件上限 256 MiB，包含正文、保存基线和编辑历史；超限或写入失败时保留旧快照并阻止退出，需保存、关闭部分标签或解决存储故障。异常中止只能恢复最近一次成功快照。
- 恢复文件位于 `%APPDATA%/com.personal.znote/recovery.json`。重启采用会话正文而非重新读取源文件；再次保存仍校验磁盘版本，外部修改或删除不会静默覆盖。原生对话框已选过的路径由 Rust 记录并恢复保存授权；关联打开文件仍需首次保存确认路径。旧版草稿迁移为未保存副本，需另存为。恢复数据损坏时保留原文件并提示，不覆盖为新会话。
- 混合换行文件必须在帮助菜单“设置”中明确选择 LF/CRLF/CR 后保存。无 BOM UTF-16 不自动猜测。GBK 无法表示的字符会拒绝保存，可切换 UTF-8。
- 保存前两次检查 revision，可检测通常的外部修改；检查与替换之间极短的跨进程竞争窗口不具备完整 CAS 保证。另存为覆盖以原生对话框确认为准。
- 使用系统 WebView2。更新包使用 Tauri updater 密钥签名；Windows 安装程序未配置代码签名证书。不自动更改默认文件关联。
- macOS 使用系统 WKWebView，最低 macOS 12.0，发布 arm64 DMG。应用采用 ad-hoc 代码签名，未配置 Apple Developer ID 签名与公证；首次打开下载的应用可能受到 Gatekeeper 限制。updater 归档另有 Tauri 签名，两者用途不同。

## 开发与构建

需要 Node.js ≥22.13、pnpm（锁文件由 8.10.0 生成）、Rust MSVC stable、Visual Studio C++ Build Tools 和 Windows SDK，以及 WebView2。

```powershell
pnpm install --frozen-lockfile
pnpm dev                         # 浏览器界面开发
pnpm tauri dev                   # 已配置 MSVC 的终端中启动桌面开发
pnpm test
pnpm build                       # 包含 Vue/TypeScript 检查
cargo test --manifest-path src-tauri/Cargo.toml --lib --locked
pwsh -NoProfile -File scripts/collect-licenses.ps1
pwsh -NoProfile -File scripts/build.ps1
```

`scripts/build.ps1` 自动载入本机 MSVC 环境，输出 `src-tauri/target/release/bundle/nsis/zNote_0.1.6_x64-setup.exe`。NSIS 安装范围为当前用户。macOS arm64 由 GitHub Actions 在 `aarch64-apple-darwin` runner 上生成 `.dmg` 和签名 updater 归档；依赖升级后重新收集许可再打包。

macOS 本地构建需要 Xcode Command Line Tools、Rust stable 与 `aarch64-apple-darwin` target，以及相同的 Node.js / pnpm；运行 `pnpm tauri build --target aarch64-apple-darwin --bundles app,dmg`，Tauri 会自动合并 `src-tauri/tauri.macos.conf.json`。必须包含 `app` 目标才能生成 updater 所需的 `.app.tar.gz` 和签名；仅构建 `dmg` 不会生成更新归档。发布配置与元数据检查使用 `node --test scripts/release-updater.check.cjs`。

推送与应用版本一致的 `vX.Y.Z` tag 会触发 `.github/workflows/release.yml`，在 GitHub Actions 并行构建 Windows NSIS 与 macOS arm64 DMG/updater 签名，随后按 `platforms` 分别生成 `latest.json`。仓库 secret `TAURI_SIGNING_PRIVATE_KEY` 保存对应私钥；本地打包更新产物时需设置同名环境变量。正式更新验证须从较低版本的安装版执行“检查更新”，确认下载、安装、重启后的帮助菜单版本号。

## 界面品质与桌面布局

编辑内容保留 6 px 顶部和左右留白。浅深主题分别校准正文、辅助文字、语法颜色、输入控件边界和焦点；应用图标与强调色保持一致。“帮助 → 关于 zNote”显示当前安装版本与许可。

Markdown 标准与紧凑宽度在 14 px 时分别约为 960 px、720 px，随正文字号成比例调整；同一宽度设置用于原位和分屏预览。模式切换按顶部文档位置恢复阅读位置。大纲字号独立于文档字号，避免放大正文后挤压导航。错误提示保留到手动关闭，成功提示短暂显示。
