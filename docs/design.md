# zNote 首版设计

zNote 面向个人日常写作和文本处理，优先满足轻量启动、顺畅输入、Markdown 排版和准确 JSON 格式化。首版是 Windows 本地应用，不依赖账号、云服务或数据库。

## 编辑体验

使用 Light 暖白纸面与 Dark 中性深色主题；侧栏提供 Markdown 大纲，中间是多标签编辑区，底部显示文件属性与光标位置。正文采用中文阅读字体，结构化文本采用等宽字体；当前主题与模块维护入口见 [前端维护](frontend.md)。常用操作保留菜单、图标按钮与键盘快捷键。

CodeMirror 6 统一承载普通文本、JSON/JSONC、Markdown。标签保存各自 EditorState 与撤销历史，只有当前文档创建编辑视图。正文不逐键复制到 Vue 响应式状态。Markdown 提供源码、按块排版与编辑的原位模式、分屏预览；原位和分屏共用 Markdown 解析与 HTML 清理，表格、公式和图表均在原位排版。点击块后回到该块源码，不提供单元格级可视化表格编辑。

## 系统边界

| 模块 | 职责 |
| --- | --- |
| Vue 3 + TypeScript | 标签、工具栏、大纲、主题、交互反馈 |
| CodeMirror 6 | 文档、选区、撤销、多光标、搜索与语法扩展 |
| Markdown-it + DOMPurify | Markdown 预览与 HTML 清理 |
| jsonc-parser + Worker | JSON 文本修改计算，不转换数值对象 |
| Tauri 2 + Rust | 原生文件对话框、编码、文件保存与恢复 |

JSON 格式化在 Worker 中计算文本 edits，通过单次编辑事务应用；文档在等待期间变化时丢弃旧结果。严格 JSON 与带注释 JSONC 分开校验，保留大整数和重复键的原始字面值。

文件读写保留编码、BOM 和换行符，不能无损编码时拒绝保存。保存检查已有版本，外部更改不得静默覆盖；写临时文件后原子替换。恢复内容存于应用数据目录，与用户实际文件分开。

预览禁用原始 HTML 与远程资源加载，不允许文档导航替换应用。桌面权限只覆盖当前窗口必要能力，不提供通用 shell 或数据库操作。

## 首版性能边界

单文件设定明确大小上限；大文档降级关闭昂贵实时排版。输入由 CodeMirror 管理，预览按需延迟更新。不能以 Tauri 包体积推断运行内存或承诺“性能最好”；冷启动、输入延迟、长文滚动和多进程内存需要真实环境测量。

## 验证

前端类型检查、生产构建和格式化边界测试；Rust 编码、保存与冲突测试；真实 Windows 应用检查打开、编辑、保存、关闭保护和重启恢复；NSIS 安装包完成当前用户安装并验证安装后启动。未覆盖项在验证记录中明确保留。
